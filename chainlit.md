# Welcome to Edu Nexus 🧠

**Edu Nexus** is a Tri-Hybrid Semantic Search Engine designed for University Curricula.

### 🚀 System Architecture

Unlike standard LLM wrappers, Edu Nexus utilizes a **"Glass Box"** reasoning engine:

1.  **🕸️ Deep Brain (Graph Engine):** Traverses Knowledge Graph nodes (Neo4j) to find structural relationships between concepts.
2.  **📚 Semantic Brain (Vector Engine):** Scans high-dimensional vector space (FAISS) for contextual similarity.
3.  **⚡ Fast Brain (Keyword Engine):** Executes BM25 lexical search for precise terminology.
