============================================================
  Edu Nexus — Command Line Instructions
  Run these commands from the project root directory:
  c:\Users\Sarvesh\Desktop\MinorProject\Edu-Nexus\
============================================================


STEP 1: Create Virtual Environment (only needed once)
------------------------------------------------------
python -m venv venv


STEP 2: Activate Virtual Environment
------------------------------------------------------
venv\Scripts\activate


STEP 3: Install Dependencies
------------------------------------------------------
pip install -r requirements.txt


STEP 4: Setup Avatar (only needed once)
------------------------------------------------------
mkdir .chainlit\public\avatars 2>nul
copy /Y logo.png ".chainlit\public\avatars\edu nexus.png"


STEP 5: Run Edu Nexus
------------------------------------------------------
chainlit run app.py


============================================================
  That's it! Open http://localhost:8000 in your browser.
  Press Ctrl+C in the terminal to stop the server.
============================================================
